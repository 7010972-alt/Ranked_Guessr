# Reflection

## Advice to Self
If I had to start this project from scratch I would have loved to focus on organization and not have "rushed" in a sense through this project. A lot of optimization could have been done but instead of going back and shortening some code I just kept on adding more of the things I wanted to make. This led to some disorganization but not enough that I had trouble working on the project. I just wish that I could have spent more time making my code look nice. Overall, I spent so much time on this project (around 4 months) and I was proud of all the things I was able to add. However, I just wish that I could have thought about cleaner solutions first before implementing what I first though of just because it would work.

## Needs and Wants
My needs to have list was fully completed. I actually finished my needs to have list quite early but I wanted to perfect some feautures like the beginners guide and expand the geohints of each country. I added cool sound and visual effects that give the game a more alive feeling. Additionally, I added a settings tab that was on neither lists but I thought it would be a good idea. Keep in mind that I had the basics of geoguessr working before the SDS started which is why my needs to have might seem a bit empty for all the things that my game has (I didn't include things I already made). As for my wants I wasn't able to get to them. I thought that it would have been super nice to have more muiltiplayer options and a global chat, but these were things that I found at the bottom of my priority list and did not end up getting to them.

## Hardest Part
The hardest part of my project was figuring out the logic for muiltiplayer. This was the first time I was configuring a muiltiplayer game and it was very difficult. I remember nights in my room at my laptop not sleeping until I fixed a couple muiltiplayer features. I implemented muiltiplayer before my SDS but I had to go back during it and tweak many things which proved to be a nightmare. At the end of the day I really like how my muiltiplayer turned out. However, it does have a lot of repetitive code across the 5 gamemodes and thinking back it could have done in a way cleaner way that I only realized later on as I got better with code.

## Problems that I couldn't Solve
There weren't neccesary any problems within my game that I couldn't figure out in the end. However, something that has been haunting me is the organization of my code. Examples of this include many z index magic numbers. Unfortunatley, I did not make a good way of changing z indexes and I was going to fix it by making the "moveLayer()" function which I did, but with so many z indexes I couldn't find the time to organize all of them. Also, many screen positioning things that are held in the fixSizes() function contain some magic numbers that were too many to sort and organize.
