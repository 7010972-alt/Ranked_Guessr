#Major Project SDS
For my major project I would like to add to my Geoguessr inspired game. I would like to add many features to make the game feel like an actual proper web game. There are many things that I would like the create with this project like more muiltiplayer modes as I think geoguessr does not have that many. I would love to have many learning systems like custom maps and hints for different areas of the world. 

##Need to Have
- global text chat, all players are connected to one chat to communicate
- custom parties, player creates room code and another player joins
- custom maps, allows the player to upload custom maps and practice on them
- satisfying effects, effects to make the game more satisfying like when they click on the map or get a good guess
- hint system, holds hints for different areas of the world showing them after a guess or saved as a library

##Nice to Have
- options for 2V2, 1V2 3V2, etc.
- a shop for custom pins, also a system to select pins like an inventory
- other cosmetic effects. Like a custom particle effect when you place your pin
- achievments, player titles
- add expiremental gamemodes, ex. infinite pins mode
