# Major Project SDS
For my major project I would like to add to my Geoguessr inspired game. I would like to add many features to make the game feel like an actual proper web game. For my SDS I would like to add to the learning and visual aspect of Geoguessr. I want players to be able to actually learn about the game so that it is actua;;y fun. I want a library type of thing where it holds many hints for areas of the world. Also, I want to add custom maps to the game where players can add their own maps to practice and what not (plus this would be very cool as there actually aren't many good free options to do this). Of course I want the game to feel rewarding in a sense by adding special cosmetics and achievments to work towards.

## Need to Have
- custom maps, allows the player to upload custom maps and practice on them
- satisfying effects, sound effects and visual effects to make the game more satisfying like when they click on the map or get a good guess
- hint system, holds hints for different areas of the world showing them after a guess or saved as a library
- a quiz system to help players geoguessr hints
- a shop for custom pins, also a system to select pins like an inventory
- achievments
- cosmetic effects. Like a custom particle effect when you place your pin

## Nice to Have
- global text chat, all players are connected to one chat to communicate
- custom parties, player creates room code and another player joins
- options for 2V2, 1V2 3V2, etc.
- add expiremental gamemodes, ex. infinite pins mode
